## notes
- Four examples are provided: climate model, delayed logistic equation, Mackey Glass equation and multiple delay Rossler system.
- In each problem, different set up and training algorithms can explored in "*_NDDE.m".
- The configuration of the neural delay differential equations can be customized in "ddeModel.m" for each problem.
- The sample code for training algorithms and auxiliary functions are in the folder "utils". Loss functions can be changed in ""grad_dde*.m".
